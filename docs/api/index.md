

# API Overview

The most useful modules:

- `digests_project.bags_pipeline.compute.unitize` — core dataclasses and helpers for Units.
- `digests_project.bags_pipeline.compute.ingest_logs` / `ingest_sessions` — normalize raw JSONL.
- `digests_project.bags_pipeline.compute.pairs` — build pairbags.
- `digests_project.bags_pipeline.compute.hydrate` — build indices and render hydrated Markdown.
- `digests_project.bags_pipeline.compute.l2` — build & write L2 digests.
- `digests_project.bags_pipeline.compute.select` — selectors for L3/L4/L5.
