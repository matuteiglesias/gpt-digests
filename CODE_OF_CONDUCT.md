# Code of Conduct

## Our standard

Contributors and maintainers must make participation respectful and harassment-free,
regardless of background, identity, experience, or ability. Be constructive, assume
good intent while addressing harmful impact, respect privacy, and focus criticism on
the work rather than the person.

Unacceptable behavior includes harassment, threats, discriminatory language,
unwelcome sexual attention, sustained disruption, deliberate exposure of private
information, or retaliation against a good-faith report.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile rather
than in a public issue. Maintainers may edit or remove contributions and may temporarily
or permanently restrict participation when behavior is harmful. Reports will be handled
as privately as practical, with conflicts of interest avoided where possible.

This code applies in project spaces and when someone publicly represents the project.
